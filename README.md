# GMJS Tour Manager

A mobile-first tour management system for GMJS, built with Google Apps Script + Google Sheets.

## Current target
- Multi-tour support
- Two or more buses
- Configurable seat layouts
- Seat booking
- Passenger management
- Payment and due tracking
- Room allocation
- Expense management
- Dashboard and reports
- Excel-friendly Google Sheets database

## Development
This repository is the source of truth. The Google Apps Script web app will be deployed from the project files here.
